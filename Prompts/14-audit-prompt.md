# FINAL CAPSTONE AUDIT

Perform a rigorous audit of the completed system.

Evaluate five dimensions:

## 1. Research correctness

Does the implementation actually correspond to the research paper?

Check:

- feature definitions
- preprocessing
- model input
- prediction
- evaluation
- interpretation
- terminology

Identify every unsupported research claim.

## 2. Functional correctness

Test:

- authentication
- IAM
- projects
- files
- collaboration
- versioning
- execution
- GitHub
- analysis
- reports

## 3. Security

Look for:

- privilege escalation
- unauthorized project access
- arbitrary code execution
- resource exhaustion
- token exposure
- injection
- WebSocket abuse

## 4. ML reliability

Check:

- missing features
- invalid input
- feature drift
- unsupported projects
- model versioning
- reproducibility
- out-of-distribution inputs

## 5. Capstone demonstration

Determine whether the system can clearly demonstrate:

User
→ Collaborative Coding
→ Python Analysis
→ Code Smells
→ Research Model
→ Defect-Risk Prediction
→ Explanation
→ Fix
→ Re-analysis
→ Comparison

Provide a prioritized list of problems.

Do not praise the system unless the evidence supports it.
